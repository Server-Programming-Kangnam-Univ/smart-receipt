# Gemini 대화 요약

**프로젝트:** 영수증 OCR 분석 서비스 (Groq API 사용) — AI 프롬프트 엔지니어 역할 명세서 작성

---

## 확정된 결정 사항

### 1. 기본 JSON 구조 확장
- `payment_info`에 `tax`(세금), `discount`(할인) 항목 추가

### 2. 프롬프트 인젝션 / 영수증 인식 실패 대응
- 흐릿한 영수증, 일반 사진, 악의적 메모 → 원인 구분 없이 `is_readable: false`로 통일
- 사용자 출력 메시지 고정: **"사진 인식이 실패했습니다. 또렷하거나, 선명한 영수증 사진을 올려주세요."**

### 3. 카테고리 고정 (6개)
- `식비`, `교통비`, `생필품`, `문화생활`, `전자기기`, `기타`
- `전자기기` 별도 분리 이유: 주 타겟이 공대생이라 전자기기 구매 빈도가 높음

### 4. 부분 인식 실패 처리
- 일부 항목만 안 보일 경우 → **전체 반려 X**, 인식된 데이터는 살리고 안 보이는 항목은 `null`
- 사용자 메시지: **"해당 부분이 인식되지 않습니다. 직접 기입하거나 다시 찍어주세요."**
- 이유: 전체 반려 시 사용자 이탈 우려

### 5. 외국 영수증 / 환율 처리
- AI는 통화 코드(`currency: "USD"`, `"JPY"` 등)만 JSON에 추출
- 원화 환산은 **백엔드가 ExchangeRate-API 호출**하여 처리 (역할 분리)
- 명세서에 **"백엔드와의 협업 포인트"** 항목으로 명시
