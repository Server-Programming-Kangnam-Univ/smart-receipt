## 1. 생성형 AI와의 대화 요약

생성형 AI(Gemini)와 약 60분간 대화하며, 영수증의 가맹점명 및 품목 인식 오류를 해결하기 위한 **이미지 전처리 파이프라인**과 **데이터 관리 시스템**을 설계하였습니다.

### 대화 흐름 요약

**[1단계] 문제 진단 및 전처리 기법 논의**
- 영수증의 그림자, 구겨짐, 흐릿한 인쇄 상태로 인해 가맹점명이 오인식되는 문제를 확인.
- OpenCV를 활용한 `Grayscale`, `이진화(Binarization)`, `모폴로지(Morphology)` 기법의 도입을 결정.

**[2단계] OCR 최적화 전략 수립 (핵심)**
- **이진화 전략**: Otsu 알고리즘을 적용하여 배경 노이즈를 제거하고 글자를 명확히 분리하기로 함.
- **모폴로지 팽창(Dilation)**: 글자의 획을 굵게 만들어 끊어진 텍스트를 연결하고 AI의 인식률을 높이는 로직 확정.
- **필터링**: 미디언 필터 등을 통한 노이즈 제거 효과에 대해 논의하고 최종 파이프라인 구축.

**[3단계] 데이터 저장 및 대량 처리 설계**
- 분석 결과가 휘발되지 않도록 `JSON` 기반의 데이터 저장 시스템 구축.
- 한 번에 여러 장의 영수증을 처리할 수 있는 `Bulk Upload` 기능의 필요성을 확인하고 API 엔드포인트 설계.

**[4단계] UI 확장 및 시각화 설계**
- 분석된 데이터를 사용자에게 효과적으로 전달하기 위해 '소비분석' 탭을 추가하기로 함.
- `Plotly`를 활용하여 카테고리별 지출 통계를 시각화하는 대시보드 구조 확정.

## 2. 담당 세부 기능 명세서

### 2.1. OCR 인식률 향상을 위한 이미지 전처리 시스템

AI 분석 전, 입력된 이미지를 최적화하여 텍스트 추출의 정확도를 극대화함.

1. **그레이스케일 변환**: 색상 노이즈를 제거하고 명암차를 뚜렷하게 함.
2. **Otsu 이진화**: 이미지 전체의 조명 상태를 분석하여 배경과 글자를 흑백으로 명확히 분리.
3. **모폴로지 팽창 (Dilation)**: $s(t) - Filter - Dilation$ 과정을 통해 글자 획을 보강하여 가맹점명 등의 고유 명사 인식 오류를 최소화함.

### 2.2. 데이터 영속성 및 데이터 통합 관리 시스템

1. **JSON 기반 저장소**: `receipts.json`을 활용하여 분석 내역(날짜, 금액, 품목, 카테고리) 및 수동 입력 데이터를 영구 보관.
2. **수동 입력 API (`/receipts/manual/`)**: 이미지 없이도 날짜, 가맹점명, 카테고리, 금액, 상태(비고)를 직접 입력하여 내역을 추가할 수 있는 기능 구현.
3. **데이터 통합 처리**: AI 추출 데이터와 수동 입력 데이터를 동일한 규격으로 통합하여, 통계 분석 및 시각화 시 누락 없는 전체 지출 관리가 가능하도록 설계.
4. **이미지 서버 보관**: 업로드된 원본 이미지를 UUID 기반으로 관리하여 보관함 기능 지원.
5. **벌크 업로드 (`/analyze-receipts-bulk/`)**: 여러 장의 영수증을 동시에 분석하고 저장하는 비동기 처리 로직 구현.

### 2.3. 소비 데이터 시각화 (Dashboard)

1. **소비분석 탭 구현**: 홈과 보관함 사이에 위치하며, 누적 데이터를 기반으로 통계 제공.
2. **차트 시각화**: 
   - 카테고리별 지출 합계 (Bar Chart)
   - 지출 비율 분포 (Pie Chart)
