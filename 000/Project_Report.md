# [기말 프로젝트] 개인 역할 및 세부 기능 명세서

**담당자**: 주안  
**담당 역할**: 서비스 UX 설계 및 지능형 데이터 분석/응용 레이어 개발

---

## 1. 역할 개요
본 프로젝트에서 **'데이터 활용 중심의 서비스 인터페이스'** 구축을 전담하였습니다. 팀원이 구축한 AI 분석 엔진으로부터 도출된 원시 데이터를 실사용자가 가치 있게 소비할 수 있도록 시각화 리포트, 지능형 자산 관리, AI 상담 시스템으로 확장하여 서비스의 전체적인 완성도를 높였습니다.

---

## 2. 세부 구현 기능 명세

### ① 지능형 소비 시각화 대시보드 (Data Visualization)
*   **월별 지출 트렌드 분석**: Pandas를 활용해 시계열 데이터를 월별로 그룹화하고 `gr.BarPlot`을 통해 지출 변화 추이를 동적으로 시각화
*   **카테고리별 지출 비율**: 사용자의 소비 성향을 한눈에 파악할 수 있도록 카테고리별 누계액을 계산하여 비율 차트 제공
*   **실시간 통계 엔진**: 지출 내역 추가 시 대시보드의 모든 통계 수치와 차트가 실시간으로 업데이트되는 반응형 로직 구현

### ② 사용자 맞춤형 예산 관리 및 알림 (Smart Alert)
*   **유동적 예산 설정**: 사용자가 자신의 소비 목표에 따라 월 예산을 직접 설정하고 관리할 수 있는 시스템 구축
*   **임계치 기반 경고 로직**: 지출액이 설정 예산의 80%를 초과할 경우, 대시보드의 게이지 바 색상을 파란색에서 빨간색으로 변경하여 사용자에게 직관적인 위기감을 주는 경고 시스템 구현

### ③ 영수증 이미지-데이터 매핑 뷰어 (Evidence Management)
*   **인터랙티브 보관함**: 보관함의 텍스트 내역을 클릭(Select)할 시, 서버에 아카이빙된 원본 영수증 이미지를 우측 미리보기 창에 즉시 렌더링하는 매핑 시스템 구현
*   **증빙 데이터 매칭**: 단순 텍스트 데이터가 아닌 실제 이미지 증빙을 함께 관리하여 서비스의 신뢰도 확보

### ④ 소비 히스토리 기반 AI 상담 비서 (AI Application)
*   **컨텍스트 주입형 챗봇**: 사용자의 최근 소비 내역(20건)을 AI의 지식 베이스(Context)로 변환하여, "식비 얼마 썼어?", "어디서 제일 많이 써?" 등의 질문에 데이터 기반으로 정확히 답하는 지능형 비서 구현
*   **상담 인터페이스**: Gradio 챗봇 컴포넌트를 활용한 실시간 대화형 UI 설계

### ⑤ 서비스 운영 및 편의 기능 (Utility)
*   **다중 파일 배치 처리**: 여러 장의 이미지를 한꺼번에 업로드하고 순차적으로 분석 엔진에 전달하는 작업 흐름 최적화
*   **데이터 익스포트**: 분석된 정형 데이터를 CSV 형식으로 변환하여 사용자가 가계부 앱이나 엑셀에서 활용할 수 있도록 지원

---

## 3. 핵심 성과 및 차별화 포인트
*   **엔진과 서비스의 분리**: AI 엔진(팀원)과 서비스 응용 레이어(본인)를 명확히 분리하여 확장성 있는 아키텍처 설계
*   **사용자 중심 설계**: 단순 기술 구현을 넘어 '예산 경고', '이미지 확인' 등 실제 사용자가 필요로 하는 편의 기능에 집중
*   **생성형 AI의 응용**: LLM을 단순 챗봇이 아닌 실시간 데이터 분석 도구로 응용하여 프로젝트의 주제 의식 강화
