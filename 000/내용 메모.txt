 1. 서비스 UI (Service UI)
   * 위치: 주안_담당기능_공유/frontend/app.py
   * 핵심 코드 내용:
       * gr.Tabs() 부분: [대시보드], [영수증 올리기], [AI 소비 비서], [보관함]으로 나뉜
         전체 레이아웃 설계
       * update_dashboard 함수: 소비 데이터를 통계 내고 그래프용 데이터로 가공하는 로직
       * gr.BarPlot 컴포넌트: 월별 지출 트렌드를 보여주는 차트 구현
       * chat_with_ai 함수: AI 비서와 대화하는 채팅 인터페이스 로직
       * set_budget 함수: 사용자가 목표 예산을 설정하고 저장하는 UI 기능
       * show_receipt_image 함수: 표를 클릭하면 영수증 사진을 띄워주는 미리보기 로직

  2. 백엔드 추가 API (Backend Additional API)
   * 위치: 주안_담당기능_공유/backend/main.py
   * 핵심 코드 내용:
       * save_receipt & load_receipts 함수: 분석 결과를 JSON 파일로 영구 저장하고
         불러오는 시스템
       * app.mount("/images", ...): 업로드된 영수증 사진을 웹에서 볼 수 있게 해주는
         이미지 서버 설정
       * @app.post("/ask-ai/"): 사용자의 질문에 소비 데이터를 바탕으로 답해주는 챗봇
         엔진 API
       * @app.get("/budget/") & @app.post("/budget/"): 월 목표 예산을 관리하는 예산 전용
         API
       * @app.get("/history/"): 저장된 모든 영수증 내역을 불러오는 API
